# 视频回归：标记、空白判定与遮罩对齐

日期：2026-11-17。使用用户录制的 `rec_5422b97b81b3`（900帧）和 `rec_7267479ca145`（608帧）。原视频未修改，样本及结果位于 `data/video_testset/recordings_20261117/`，不纳入Git。

## 已确认的原因

1. **标记锚点不是答题位置**：例如数学第二页第8题，旧锚点是 `[1195,107]`，答题区域却是 `[521,269,110,59]`；第16题也有明显横向偏移。多候选答题区以前总用第一个区域画圈，实际笔迹可能在另一个区域。
2. **纸面局部弯曲导致印刷残差**：全页单应矩阵无法完全消除局部位移，错位题号、横线、印刷字被当成新增手写。HWR又允许截断JSON、重复数字、题号等作为高置信度答案。
3. **遮罩重建方式有误**：旧实现按整页顶边角度创建旋转外接矩形，并把标记和留白纳入开孔，因而没有沿题目真实四边形对齐。

## 修复方式

- 后端根据实际 `primary_area_index` / `ink_bbox` 生成 `mark_quad`，不再采用旧 `mark_anchor`。墨迹框和标记框使用同一个H投回原图。
- 前端将勾叉、圈线投射到局部四边形，不再用整页角度加固定偏移；圈线包住紧墨迹框，避免横穿笔画。
- 遮罩开孔和白色边框直接使用 `q.quad`。镜头缩放包围盒独立计算，不再影响遮罩形状。
- 浮动红色文字批注不再覆盖照片，详细批注保留在右侧解析。
- 模板印刷遮罩在局部上下文中对齐，观察图不移动；返回的墨迹坐标仍属于原全页warp坐标域，避免重复叠加局部偏移。
- 不只检测中心84%，保留测试中的浅色、细线和边缘笔迹；空白区域不再交给模型猜答案。
- 原图覆盖率不足98%、局部配准低置信度或HWR格式异常时进入待确认，不能把未知硬判为空白或对错。
- HWR合法单选字母支持A–H，避免误拒绝五选项题的E；截断JSON、重复串和印刷题号不再作为可靠作答。

## 边界

以上数字只说明这批样本及对应回归已通过，不能推断所有光线、纸张变形和书写条件都100%正确。没有新增专门的手部分割：完全遮住不含印刷特征的纯白区域仍不能保证识别遮挡。新遮罩与后端题框严格共用坐标，也不意味着弯曲纸面的全局OCR定位在物理上完全无误。

前端已验证原始照片诊断叠加图、SVG数学几何与语法；不把这些测试冒充完整浏览器交互验收。
